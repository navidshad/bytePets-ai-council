# Challenge Blueprint — BytePets

> Which feature answers which part of the Hack4Vilnius brief. Full details: `prd.md`.

| Part of the brief | Features that answer it |
|---|---|
| **Find** info easily, **in one place** | Map and list with filters; emergency button; English and Lithuanian |
| **Vet services** (clinics, pharmacies) | Vets and pharmacies from the VMVT register and OpenStreetMap; 24/7 vets checked by hand |
| **Pet-friendly places** | Pet-friendly group with pet rules ("inside OK", "terrace only") |
| **Walking areas** | City walking areas on the map; Walk-Mate (create, edit, cancel, join, leave, 3D preview) |
| **Lost or found animals** | "I lost a pet" / "I found a pet" buttons; board; AI matching; both sides confirm |
| **Other assistance** | Emergency button; assistant that takes a report in plain words |
| **Add** | Add a place by pinning it; post lost or found; create a walk |
| **Verify** / **reliability** | "Still true?" Yes / Something's wrong; trust badge; source label |
| Info gets **outdated** | "Confirmed X days ago" line; places go stale on their own |
| **Share** with others | Public link for every place, post and walk |
| **Community-based** | Everyone adds, confirms and reports; walks ask "is this area still OK?" |
| **More pet-friendly Vilnius** | Live counters; Walk-Mate gets owners out together |
| **Data sources** in the brief | City walking areas, VMVT vets and pharmacies, OpenStreetMap, a hand-made pet-friendly list |
